五月份把工作区托管给 Agent 之后，我的 Token 用量就一路失控（详见 {% post_link 三个月Token消耗暴涨13倍-我的AI工作流演变记录 [《三个月Token消耗暴涨13倍》] %}）。用量上去了，只靠官方 API 按量付费实在肉疼，于是这半年我把能买到的 Token 套餐（包月／包量）基本都试了一遍——两家国内云厂商，五家第三方。

这不是推荐榜，就是把手上的体验记一遍：好的地方说好，难受的地方也不客气。

## 国内两家云厂商：模型跟得快，429 也来得快

### 阿里云

阿里是我最早买的一家，理由很简单：国内模型跟得快。新模型基本上是跟着厂商的发布节奏上，不用等第三方去转接。我主力跑的就是国产模型，所以这一点非常关键——上下文长度、工具调用这些，官方永远是最全最及时的。

但它也是我见到 429 最多的一家：**高峰期限流相当严重**，而且不挑任务，急活儿正好撞上高峰就只能干等。更难受的是有一段时间它还限售，想续费都续不上。

按我最近看到的资料，它的 Coding Plan 已经迁进了「大模型服务平台 TokenHub」，还是 Lite／Pro 两档的老结构，价格基本没动。产品在换壳，体验没换。

### 火山引擎

火山是紧接着阿里买的，原因也一样：国内模型跟得快，价格还便宜一点。

问题也一样：**高峰 429 时不时就来**，万一碰上急任务真的很难受，而且同样有限售。

它比阿里还多一个坑：**计费规则复杂**。面板上同时摆着好几套口径的数字——按模型分的、按池子分的、按套餐分的，一眼根本看不出来"我这个月到底还剩多少可用"。对一个用量按亿算的人来说，看不见用量比被限流更让人焦虑。

小结一句：云厂商的 token 套餐，本质是把共享算力打折卖给你，高峰期你就是被砍掉的那一部分。便宜是真的，稳定是打了折的。

## 第三方：便宜是真便宜，但各有各的花活

### opencode go：性价比标杆，也是缩水标杆

opencode go 是最早把"10 刀换 60 刀额度"这个比例做出来的厂商（这个 10:60 后来差不多成了行业起步价）。好处很直白：上面挂的模型都是针对 agentic coding 挑过、测过的，配上 opencode 本身用着确实顺。

然后 DeepSeek 官方涨价，风波就来了。社区当时的统计是 v4 flash 这一档的额度缩得相当夸张（有说缩水 88% 的），双倍活动也结束了，群里一度全是"才用了十块钱就提示本周额度用完"的反馈。我自己那段时间用起来也很别扭，额度像被抽走了一样。

好消息是这事最后收了个尾：现在的 cheapseek 计划第三阶段，DeepSeek 这一档回到了 80 刀的额度——官网上 Go 10 刀／Go Plus 40 刀两档，DeepSeek V4.1 Flash 那行标的月额度正是 $80／$160。

坏消息是它开始管客户端了：**现在请求头有硬性要求**，不带 `x-opencode-session` 这类头，补全请求直接 400 MissingSessionID。翻译一下就是：套餐更希望你在 opencode 里用。想把这些额度接到别的 Agent 上？可以，但会时不时被这类限制绊一下。

### R4code：查不到出处的小厂，早期真香

R4code（r4.codes）是我在某次福利活动里发现的。第一次点进官网我愣了一下——**查不到什么公司背景**，只有"我们是一家专门做国产模型 Coding Plan 的服务商"这种介绍。典型的小厂。

但早期体验是真好：人少的时候速度快、缓存命中高，价格又低，值到不太真实；审核也比别家宽松，基本上付了钱就能用。宣传话术里写的折扣也很凶（Kimi K3 0.28 折、GLM 5.2 0.42 折这种），一看就是来抢人的。

后来人多了，就开始不稳定了：速度时好时坏，高峰期明显不如以前。它拉新的方式也很有这个圈子的风格——在社区发福利、送额度、抽套餐，OpenCode GO 出事那阵子还专门发了"接收难民"的帖子。营销声量比资质响亮太多，这也是我不太敢把主力任务压在它上面的原因。

### clinepass：稳，但国内模型慢半拍

clinepass 是 Cline 自己出的套餐，9.99 刀一个月，覆盖的全是开源权重模型（GLM、Kimi、DeepSeek、MiniMax、MiMo、Qwen 这些），和 Cline 的 IDE／CLI 配合得很顺，属于"买它就是因为不想折腾"的选择。

缺点也很明确：**国内模型上得慢**。DeepSeek V4.1 发布之后，其他家大部分立刻就上了，clinepass 我印象里至少慢了半个月。对主力用国产模型的人来说，慢半个月基本等于这个月白买。

### command code go：opencode go 风波之后捡到的

command code go 是我在 opencode go 那波风波之后才发现的。当时的配额比例是 10 对 60，速度也不错，是那段时间用下来最省心的一个。

有意思的是它的价格表比我换套餐还勤：我买的时候是 10:60 的结构，现在官网上已经变成了 Go 档 $1 含 $10 额度、GOAT 档 $10 含 $80 额度这样的新结构。对用户当然是好事，但也提醒你——**别把任何一个套餐的档位数字当真**，下个月可能就变了。

### open design：额度喊得最高，面板什么都不给看

open design（open-design.ai）给我的感觉是"看着大家都出套餐，它也出了一个"。它本职是开源的 Claude Design 替代品，做设计工作台，套餐更像是顺手加的副业。

它现在是宣称额度最高的一家：Go 档 10 刀／月，**每月最高总额度 $120**，也就是 10:120 的比例；往上 Plus 20 刀／$180、Pro 100 刀／$480，并发也给得慷慨（Go 10 个、Plus 20 个、Pro 30 个）。速度和并发我实际用下来确实没什么可挑的。

但有两件事让人没法放心：

1. **管理面板暂时不提供详细数据**。宣称的 $120 到底怎么算、用掉多少，全靠它自己说，实际未知；
2. Go 档不含"套餐模型"额度，那些最贵的模型（Astra、Claude 这些）在 Go 档里直接标着"暂不支持"。

所以我对它的态度是：速度敢用，主力不敢压。

## 踩出来的几条规律

1. **10 刀换 60 刀是行业起步价，现在卷到了 10 刀换 120 刀。** 但额度从来不是白给的：要么面板不给你看详情，要么靠限流、缩水慢慢省回来。
2. **云厂商跟模型最快，第三方永远慢半拍**，最慢的能慢半个月——而模型迭代速度，半个月就是一代。
3. **越新越便宜的小厂，越容易在稳定性和透明度上掉链子。** 早期体验好，很大程度上只是因为人少。
4. **请求头和客户端绑定是变相锁定。** 表面上是"只能在我的客户端里用"，实质是抬高你的迁移成本。
5. **面板透明度是长期可用的信号。** 连用量都不敢给你看清楚的套餐，早晚会在别的地方让你还回来。

## 我现在怎么办

- **主力任务压在稳的上面**：正经活交给云厂商的套餐或 command code go，新开的小厂只用来跑边角任务和实验；
- **每家只买最值的档位，然后多买几家**：这个思路之前写在 {% post_link Omniroute-DeepSeek涨价后-一个Key管起所有Token-Plan [《Omniroute》那篇] %} 里，到今天我还是觉得它最划算，顺手还能绕开单家的 5 小时限额；
- **不追"最高额度"的宣传**：额度写在广告上的时候是数字，落到你账号里又是另一回事。

最后说明一下：这篇全是个人一手体验，价格和档位一周一变，文里的套餐信息是我 2026-10-17 查官网时看到的，以官网为准。你最近在哪家用着舒服？评论区聊聊。
