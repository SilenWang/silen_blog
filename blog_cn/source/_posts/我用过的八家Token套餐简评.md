五月份把工作区托管给 Agent 之后，我的 Token 用量就一路失控（详见 {% post_link 三个月Token消耗暴涨13倍-我的AI工作流演变记录 [《三个月Token消耗暴涨13倍》] %}）。8 月 DeepSeek 涨价，官方 API 实在用不起，只好去找便宜的第三方。于是这半年，市面上能买到的 Token 套餐（包月／包量）我基本都试了一遍——三家国内云厂商，五家国外的。

这不是推荐榜，只是把手上的体验记一遍：好的地方说好，难受的地方也如实记录。

## 国内三家云厂商：模型跟得快，429 也来得快

### 阿里云

阿里是我最早买的一家，理由很简单：国内模型跟得快，新模型基本跟着厂商的发布节奏上。

但它也是我见到 429 最多的一家：**高峰期限流相当严重**，急活儿正好撞上高峰，就只能干等。更难受的是有一段时间它还限售，感觉超售严重。

按我最近看到的资料，它的 Coding Plan 已经迁进了「大模型服务平台 TokenHub」，还是 Lite／Pro 两档的老结构，价格基本没动。产品换了壳，体验没换。

### 火山引擎

火山是紧接着阿里买的，原因也一样：国内模型跟得快。

问题也一样：**高峰 429 时不时就来**，万一碰上急任务真的很难受，而且同样有限售。

它比阿里还多一个坑：**计费规则复杂**。火山自己发明了一套积分（credit），每个模型的折算还不一样，一眼看不出来"我这个月到底还剩多少可用"。

### 华为云：贵

5000 万 token 卖 50 块，最贵，没有之一。别家几十块就能买到十亿级别的量，而华为这 5000 万赶上高峰一天就烧完了——纯冤种。

## 国外厂商：便宜是真便宜，但也有花活

### opencode go：曾经的性价比标杆，现在是缩水标杆

opencode go 是最早把"10 刀换 60 刀额度"这个比例做出来的厂商（这个 10:60 后来差不多成了行业起步价）。好处很直白：上面挂的模型都是针对 agentic coding 挑过、测过的，配上 opencode 本身用着确实顺。

然后 DeepSeek 官方涨价，风波就来了。社区当时的统计是 v4 flash 这一档的额度缩得相当夸张（有说缩水 88% 的），双倍活动也结束了，那阵子社区里全是"才用了十块钱就提示本周额度用完"的反馈。

好消息是这事最后收了个尾：官方推出了 cheapseek 计划，一步步把 DeepSeek 的额度提了回来。现在的第三阶段，DeepSeek 这一档回到了 80 刀——官网 Go 10 刀／Go Plus 40 刀两档，DeepSeek V4.1 Flash 那行标的月额度正是 $80／$160。

坏消息是它开始管客户端了：**现在请求头有硬性要求**，不带 `x-opencode-session` 这类头，补全请求直接 400 MissingSessionID。翻译一下就是：套餐更希望你在 opencode 里用。眼下还能靠额外设置把这个头补上，但难保哪天不会干脆给 opencode 强制引流。

### R4code：查不到出处的小厂，早期真香

R4code（r4.codes）是我逛社区时偶然发现的。第一次点进官网我愣了一下——**查不到什么公司背景**，只有"我们是一家专门做国产模型 Coding Plan 的服务商"这种介绍。

但早期体验是真好：人少的时候速度快、缓存命中高，价格又低，值到不太真实；内容审核也比别家宽松，做点系统设置之类的操作，几乎不会被拦。

后来人多了，就开始不稳定：速度时好时坏，高峰期明显不如以前。

### clinepass：稳，但国内模型慢半拍

clinepass 是 Cline 自己出的套餐，9.99 刀一个月，覆盖的全是开源权重模型（GLM、Kimi、DeepSeek、MiniMax、MiMo、Qwen 这些），和 Cline 的 IDE／CLI 配合得很顺，属于"买它就是因为不想折腾"的选择。

缺点也很明确：**国内模型上得慢**。DeepSeek V4.1 发布之后，其他家大部分立刻就上了，clinepass 我印象里至少慢了半个月。对主力用国产模型的人来说，慢半个月基本等于这个月白买。

### command code goat：opencode go 风波之后捡到的

command code goat 是我在 opencode go 那波风波之后才发现的。当时的配额比例是 10 对 60，速度也不错，是那段时间用下来最省心的一个；到现在也还算稳定。

### open design：额度喊得最高，面板信息有限

open design（open-design.ai）给我的感觉是"看着大家都出套餐，它也出了一个"。它本职是开源的 Claude Design 替代品，做设计工作台，套餐更像是顺手加的副业。

它现在是宣称额度最高的一家：Go 档 10 刀／月，**每月最高总额度 $120**，也就是 10:120 的比例；往上 Plus 20 刀／$180、Pro 100 刀／$480，并发也给得慷慨（Go 10 个、Plus 20 个、Pro 30 个）。速度和并发我实际用下来确实没什么可挑的，所以目前它和 command code 是我的主力。

唯一的问题是它的控制面板只按百分比展示额度，既看不到具体请求数，也看不到 token 数——10:120 是不是虚数，暂时无从验证。

最后说明一下：这篇都是个人一手体验，价格和档位经常变，文中的套餐信息查询于 2026-10-17，不保证之后仍然有效。
